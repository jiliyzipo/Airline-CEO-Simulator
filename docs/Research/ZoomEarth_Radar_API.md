# Zoom Earth 雷达云图接口分析

> 目标：用 Zoom Earth 的全球雷达云图瓦片，替换当前 RainViewer 实现，达到更接近「飞常准」的观感。
> 结论：**可调用，全球覆盖，免费、无 Key、无登录、无防盗链**（已实测直接下载成功）。
> 唯一额外成本：瓦片是 **WebP 格式**，Unity 原生不支持解码，需引入第三方库。

详见仓库历史版本；运行时相关代码（`MapWeatherTileLayer` / `WebPTextureUtil` / `UIWeatherRadar` / `libwebp`）已删除。
