## 2. 峰刻判据（闭式，已穷举验证）

```
峰刻留得出余量 ⟺ floor(n·C·r) ≤ (C−1)·n + 3
n = 段内刻数，C = 每刻每方向容量，r = 占用率
```

穷举 n∈{13,16,20,40} × C∈[1,40] × r∈{0.55…0.92} 共 1440 组，反例 0 组。粗判据 1/(1−r) 差一位。

| 占用率 | n=13 | n=16 | n=20 | n=40 |
|---|---|---|---|---|
| 60% | C≥2 | C≥2 | C≥3 | C≥3 |
| 75% | C≥3 | C≥4 | C≥4 | C≥4 |
| 87% | C≥6 | C≥6 | C≥7 | C≥7 |
| 90% | C≥7 | C≥8 | C≥9 | C≥10 |
| 92% | C≥9 | C≥10 | C≥11 | C≥12 |

修正上一轮：D16·87% 下 08:00 有余量是 12 场（真实哈希），不是 15 场；「欧亚门户一座都没有」作废（CAN 可拿 2 条）。

## 4. 机场不设上限

通过：无 81/103/104 定长数组或遍历上限。

阻断：
1. 机场主键只有 IATA，无 airportId / ICAO；四表与存档全用 IATA 关联。
2. `All` 是静态只读字面量、元素 struct，无运行时 add 路径。
3. 容量烘焙成 `int[4]`，第三旋钮无处挂载；`FindByCode` 返回 struct 副本。
4. 无机场时区；`LocalUtcOffset` 是运行机器时区。
5. 性能：`FindByCode` 线性扫描且被逐刻调用。

四表覆盖：目录 104 / 地理 104 / 城市经济 104 / 跑道 88（缺 16 座）。

## 5. 接受的批评

1. 统计口径混用：每个数字必须带分母与算法版本。
2. 不得把中国机场峰刻未解锁全归因申报值，应三分（容量 C / 占用率 r / FillWave）。

## 6. B 实施陷阱

1. `BandGrid` 按分钟升序 → 夜班网格是 [00:00…05:45, 20:00…23:45]，列序会错。
2. `MatrixGrid` 裁剪不支持跨午夜。
3. `WindowStart/End`（需求波窗口）仍按旧假设，须一并审计。
