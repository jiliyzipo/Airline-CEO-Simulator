# P23 · 教程与引导文案重写（2026-10-25）

## 一句话

引导线不再卖一个「86 分、客座率 81%、回本 8 个月」的假数字，而改教**怎么不再逐页点**：
S6 从「再开一条线」的销售话术，改成底栏命令台的五类用法；文案里的钱一律取自常量。

## 一、为什么这不是润色

三类问题，每一类都会让玩家做出错的决定：

1. **假精确数字**。S0/S1 写着「日均 O&D 客流 2.5 万」「竞对客座率 89%」「综合评分 86 分」
   「预估首年客座率 81%」「投资回收期 8～10 个月」—— 这五个数在代码里**都算不出来**，
   是手写的。玩家会照着它判断「这条线稳」，而真正的 RPM 评估台给的是另一个分。
2. **文案与入账不同源**。S5 说「净利润 6.2 万」，`ApplyFirstFlightRewards` 也写 `+6.2f` ——
   看着对上，其实是**两处字面量**：哪天结算改成 5，信里仍会印 6.2。这类漂移只能靠人肉比对发现。
3. **单位不一致**。收件箱里的引导件写「16.2 万美元 / 300 万美元」，引导弹窗写「16.2 万元 / 300 万」，
   而全游戏现金单位是**万美元**。同一笔钱在相邻两块界面上是两个量级。

## 二、改了什么

### 1. 数字：要么来自常量，要么不写

| 位置 | 旧 | 新 |
| --- | --- | --- |
| S2 启动资金 | 硬编码「300 万」 | `AdvisorTutorialScript.StartupCostText` → 取 `ActionExecutor.OpenRouteStartupCost` |
| S2 财务意见 | 「回本周期约 8 个月」 | 「占当前现金 X%」（可算的替代品） |
| S1 RPM 卡 | 「86 分 / 81% 客座率 / 16.2 万元」 | `RouteDailyBaseline`（真实基准）+ 一句「分值与时段以 RPM 评估台当场测算为准」 |
| S5 结算 | 「18.4 收入 / 12.2 成本 / 89% 客座率 / +0.3 月跑道」 | `FirstFlightNetProfit` / `FirstFlightBoardGain`（**入账用的同一对常量**） |
| 收件箱引导件 | 「RPM 综合评分 86 分」「16.2 万美元」字面量 | 指向评估台 + `RouteDailyBaseline` / `StartupCostText` |
| 全文单位 | 「万元」混用 | 统一为「万美元」 |

`ApplyFirstFlightRewards` 同步改为用 `FirstFlightNetProfit` / `FirstFlightBoardGain` ——
文案与入账从此**物理上不可能分叉**。

### 2. S6：从「再开一条线」改成「换一种操作方式」

旧版是第二条航线的推销（成都—上海 12.8 万 / 79 分 / 2 家航司，三个数同样无处可查）。
新版教的是命令台，五类各给一句**能直接照抄**的话：

```
· 问情况：财务还能撑几个月           → 财务部回函
· 开航线：开通成都—上海               → 运营部把开航研究会纪要送进收件箱
· 增运力：买 2 架 A320neo            → 机队发展部发购机请示
· 补人手：招聘 10 名飞行员            → 人力资源部发招聘请示
· 找钱　：申请银行贷款                → 财务部发融资请示
```

并且明说边界：「要动钱、动编制、动机队的事，命令台**只发请示**，批不批仍是您说了算。」
末句带上 P21 的「历史 / 收藏」，因为这两件事只有说过一句之后才用得上。

按钮也换了：主按钮从「打开 RPM 评估」改成「试试命令台」，点下去**把光标放回底栏**
（新增 `CommandBarView.FocusInput()`）—— 说完就找不到入口的引导，等于没教。

### 3. 占位语：每条提示补一个「能办的事」

`CeoCommandRouter.PageHint` 原来只写问句。命令台现在也有「写」，只教问句会让玩家以为这里只能问：

| 页 | 提示里新增的例子 |
| --- | --- |
| 财务 | 要钱说「申请银行贷款」 |
| 人力 | 要人则说「招聘 10 名飞行员」 |
| 机队 | 买机说「买 2 架 A320neo」 |
| 战略 | 真要开就说「开通北京—纽约」 |
| 运营（默认） | 开线说「开通成都—上海」 |

## 三、回归怎么钉

`Editor/TutorialCopyRegression.cs`（NUnit 入口 `TutorialCopyTests`）**不断言措辞**——文案会改，
断言措辞只会让人改文案时顺手改测试。它钉两件事：

1. **文案教的句子，命令台必须真的听得懂**。把占位语与 S6 里点名的 11 句全部丢给
   `CeoCommandRouter.Route`，核对落点（财务回函 / 开航 Act / 购机 Act / 招聘 Act / 融资 Act /
   可行性 Analyze / 公司整体顾问）。教一句系统不认的话，比不教更糟：玩家会以为是自己说错了。
2. **文案里的数来自常量**：`StartupCostText == $"{OpenRouteStartupCost:F0} 万美元"`，
   且 `FirstFlightNetProfit / FirstFlightBoardGain` 存在且为正。

## 六、已知边界

1. **S1 仍不给分数**。引导里没有现成的 RPM 测算上下文（真算要拉起评估台那一套），
   所以文案改成指向评估台，而不是编一个数。要「引导里也有真分」得先有 `RpmPreview` 的 SZX-PEK 快照。
2. **S5 是演示结算**：`+6.2` 与 `+5` 不是航线跑出来的，是引导脚本直接入账的。
   文案已注明「引导演示结算」，避免玩家把它当成真实首航利润口径。
3. 术语未做本地化拆分（RPM / O&D 之类）——O&D 那句已随假数字一起删掉。
