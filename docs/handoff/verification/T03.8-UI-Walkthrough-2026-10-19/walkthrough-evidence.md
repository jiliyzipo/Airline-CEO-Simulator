## 走查中登记的缺陷与修复

| ID | 现象 | 根因 | 修复 |
|---|---|---|---|
| D1 | 航班号无关键词链接 | `TermNavMap` 只收录机号 / 三字码对 | 新增 `flight:` 链接 → `n43`，按航线现算号段；边界只认 ASCII 词字符（`char.IsLetterOrDigit` 会把汉字判为字母） |

   该词条只在排班待批的「航班计划呈报」邮件中出现。本档无此前提，
   **跳转有效性未验证**。
2. **D1 / D2 / D3 属 UI 交互行为**：EditMode 套件未直接覆盖关键词包裹、
   正文滚动位保持、航线上下文回写。这三点只有本文件的人工观察作为证据。
3. **D4 只覆盖成功办理口径**：指令失败 / 驳回的复核报告仍为即时投递，
   这是有意保留的行为，非遗漏。
4. **T02 clean-checkout 闸门仍为红**：属 HEAD 遗留（`git clone` 逐字节比对），
   非本阶段引入，本阶段未修复。
