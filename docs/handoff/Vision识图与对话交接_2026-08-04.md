## 1. 核心结论（必读）

1. **当前对话使用的 DeepSeek 模型不支持直接粘贴图片**。  
   粘贴图片会触发 API 错误：
   ```text
   Failed to deserialize the JSON body into the target type:
   messages[N]: unknown variant image_url, expected text
   ```
   原因：请求体里出现了 `image_url`，DeepSeek 只接受 `text`。

2. **本地图片识别已打通**，走阿里云百炼 Vision API（`qwen3.7-plus`），不是 Cursor 原生看图。

3. **正确用法：给图片绝对路径，不要粘贴图片到聊天框。**

4. 已添加 **Cursor 用户级全局规则**（所有窗口生效）：
   - 标题：`Vision 识图（百炼）`
   - ID：`17141150`
   - 新窗口若未生效，执行：`Ctrl+Shift+P` → `Developer: Reload Window`
