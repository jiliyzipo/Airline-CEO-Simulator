### B1 的算术核验（为什么 8 个数能自证是账本摊的）

`TakeoverCostLedger` 的四段归属是固定权重：hq（总部/地面）45/10/10/10/15/10 给运营/市场/战略/财务/董事会/安全；
fleet（机务/人力/运营）55/25/20；debt 100% 财务；insurance 100% 安全。
用实机读数反解，每一段都对得上：

| 反解 | 算式 | 实机 |
|---|---|---|
| fleet 段 | `500 ÷ 0.55 = 909`；`909 × 0.25 = 227` ✓ 人力 | 227 |
| hq 段 | `22 ÷ 0.10 = 220`；`220 × 0.15 = 33 ≈ 34` ✓ 董事会（末项取残差） | 34 |
| 运营合计 | `0.45×220 + 0.20×909 = 99 + 182 = 281 ≈ 283`（chg hq≈224 时 283） | 283 |
| debt 段 | 财务 = debt = 290 | 290 |
| insurance 段 | 安全 = insurance = 171 | 171 |

四段合计 `224 + 909 + 290 + 171 = 1594`（月成本），份额即上表比例。**这不是「另一套写死的数字」**：
它由 `55%/25%/20%`、`45%/10%/10%/10%/15%/10%`、`100%` 三组权重与四段金额唯一决定，任何一项变了比例都会跟着变 ——
这正是 B2 要再证一次的。
