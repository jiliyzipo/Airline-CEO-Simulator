## 1. 先测量，不猜

| `Editor.log` 的 `Project … Loading completed in` / `Asset Pipeline Refresh` / `Domain Reload Profiling` | 工程启动、资源库刷新、脚本编译、域重载的总账 |

| `[playboot]`（`PlayBootTimingRunner`，批处理） | 一次可复现的「真进 Play」总时长，用于改前改后对比 |


## 7. 副作用修复：程序化图标在第二局变成纯色块（2026-11-07 晚，用户报障）

### 7.1 现象

用户点了几次 Play 之后：**顾问气泡、航线图标、顶栏设置齿轮、倍速箭头全部消失，位置只剩一块纯色方块**；
同一屏里地球、云朵、雷达图标**正常**。这条「有的坏有的好」是定位的关键线索。

### 7.2 根因

`UIFactory` 里这批图标是**运行时** `Sprite.Create` 出来的（白色形状 + alpha，靠 `Image.color` 上色），
静态字段缓存。缓存写法是 `??=`：

```csharp
public static Sprite GearSprite => _gearSprite ??= BuildGearSprite(64);
```

`??=` 用的是 **C# null 语义**。关闭域重载后静态字段跨局存活，而退出 Play 时 Unity 会销毁这些运行时
对象 —— 销毁后的引用**不是** C# null。于是第二局 `??=` 认为「已缓存」，把一块**已销毁的精灵**交给
`Image`，UGUI 画不出图形，就退化成实心色块。

对照证据：同一批里 `GlobeSprite` / `CloudSprite` 走的是 `if (_x == null)`（Unity 重载判等，认得出假 null），
而且它们来自 `Resources` 里的 PNG 资源、退出 Play 不会被销毁 —— **所以正好是「PNG 图标正常、程序化图标全白」**。

### 7.3 改动

| 文件 | 改动 |
| --- | --- |
| `Assets/Scripts/UI/UIFactory.cs` | 10 处 `??=` → `if (_x == null) _x = Build…;`（含 `_ffSprites[]` 数组槽位）；新增 `[RuntimeInitializeOnLoadMethod(SubsystemRegistration)] ResetSpriteCaches()` 每局清缓存 |
| `Assets/Tests/EditMode/UIFactorySpriteCacheTests.cs`（新增） | 5 条用例，用 `DestroyImmediate` 复刻「对象已销毁但静态引用还在」的条件，并钉住 Prefab 圆角补回 |
| `Assets/Scripts/Editor/PlayBootTimingRunner.cs` | 每轮新增 `[playboot] 第 N 次 图标 …` 一行，按 Unity 判空点名四个图标 + 统计场景内「引用在、对象已销毁」的 Image |

### 7.5 顺带修掉的历史遗留：Prefab 版面的圆角（用户裁决「补回」）

探针曾报 `场景内已销毁精灵引用=1 个（Cockpit_Canvas/Panel_Shell_n0）`。查证结论：

- **与 §7 的图标 bug 无关**：把域重载重新打开（`m_EnterPlayModeOptionsEnabled: 0`）再跑，计数仍是 1；
- 原因是**预制体存不下运行时精灵**：`Panel_Shell_n0.prefab` 里 `m_Sprite: {fileID: 0}`，
  但 `m_Type: 1`（Sliced）、`m_PixelsPerUnitMultiplier: 1.2` 都还在 —— 圆角精灵是 `UIFactory`
  运行时生成的贴图，不是资产，保存时必丢；
- 影响：从 Prefab 建出来的底栏与页面**全是直角**，和在代码里现建的同类面板长得不一样。

改动（用户选 `rehydrate`）：

| 文件 | 改动 |
| --- | --- |
| `Assets/Scripts/UI/UIFactory.cs` | 新增 `RehydrateRoundedSprites(GameObject)`：只给「`type == Sliced` 且 `sprite == null`」的 Image 补回 `RoundedSprite`；`TryInstantiatePrefab` 内自动调用 |
| `Assets/Scripts/UI/PrefabNavIntegration.cs` | 实例化底栏 Prefab 后补回 |
| `Assets/Scripts/UI/Navigation/NavigationRouter.cs` | 实例化页面 Prefab 后补回 |
| `Assets/Scripts/UI/Framework/ScrollListPanel.cs` | 实例化列表模板后补回 |
| `Assets/Tests/EditMode/UIFactorySpriteCacheTests.cs` | 新增 `Rehydrate_FillsOnlySlicedImagesWithoutSprite`：只补 Sliced 空精灵，不动 Simple、不覆盖已有精灵 |

结果：`场景内已销毁精灵引用` 由 **1 → 0**；底栏与 Prefab 页面恢复圆角。
