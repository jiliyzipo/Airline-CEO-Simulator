## 1. 先开通通告、隔几小时再询价

### 病根（两处，第二处更要紧）

`TransitionBusinessLogic.MaybeUnlockReports` 旧逻辑：

- 通告与询价**都**用 `InboxCadence.ProgressReady`（同一个 +6 小时）投递 → 同一分钟并列躺进收件箱，
  玩家看不出「先开会通告、再谈买卖」的先后（正是用户看到的图一）；
- 更糟的是：报价已存在时，**通告本身**被写成 `needDecision=true` 的待批件并带上 `payloadCsv`，
  紧接着 `FlushInquiry` 又把**同一批单号**另发一封询价件 →
  收件箱里两封待批件抢同一批报价，签掉一封，另一封的单号就作废（静默失效）。

### 改法

| 位置 | 改动 |
|---|---|
| `InboxCadence` | 新增 `InquiryHours = 4` 与 `InquiryReady()`（= `ProgressHours + InquiryHours`），并在注释里写明「通告讲市场开了，询价讲有一单生意」为何必须是两封信 |
| `MaybeUnlockReports` | 通告**恒为** `Report()`（`status=approved`、`needDecision=false`、**不带单号**）；正文改说「报价已上板，询价请示另函（约 4 小时后）」 |
| `MaybeUnlockReports` | 新增 `MarkFreshForInquiry(gs, kinds)`：把当前在板的该类报价并入 `_freshOffers`，交给 `FlushInquiry` 另函请示 —— 否则通告日之前就摆着的常驻报价会被「只发通告」藏起来 |
| `QueueInquiry` | 投递时点由 `ProgressReady` 改为 `InquiryReady` |

净效果：**通告一封（通报件）+ 询价一封（待批件，晚 4 小时）**，同一批报价只有一处可签。

## 2. `购买SIN 12:00时刻槽` 收到无关邮件

### 病根

这句话里唯一像部门词的只有「时刻槽」，命中 `CeoCommandRouter.OpsWords` → 被当成一句「汇报运营情况」，
运营部回了一封「8 条航线 · 周 112 班 · 准点 80%」的网络总账。
槽没买、现金没动、台账没动，**却像受理了一样** —— 比回「没听懂」更糟。命令台根本没有「买卖时刻槽」这个意图。

### 改法

| 位置 | 改动 |
|---|---|
| `CeoCommandRouter` | 新增话题 `TopicSlotDeal` + `CeoAsk.slotBuy`；新增 `TryReadSlotDeal()`，**排在部门词表之前**（与关线/运力调令同一层）。判据：句中确有「时刻槽/槽位」+ 有「购买/申请」类动词 + 不是问句。参数不全时 `ok=false` 并附引导，**仍返回 true** —— 句子已经点明是买卖时刻槽，掉进词表只会换来一封不相干的汇报 |
| `CeoCommandRouter` | 新增 `ReadSlotAirport()`：三字码与中文名都认，中文名取**最长命中**（「上海浦东」不被「上海」抢先认成虹桥） |
| `SlotMarketLogic` | 新增公开的 `TryFindOnShelf(gs, airport, clock, out listing)`（原先 `FindOnShelf` 是私有的，命令台进不来） |
| `DeptReportLogic.Actions` | 新增 `SlotDealDirective()`（预检：无挂牌/现金不足时**如实说不成**，不发信）与 `RunSlotDeal()`（买入 → `SlotMarketLogic.Buy` 当场成交；申请 → `InboxManager.QueueApplySlots` 递协调池提案） |
| `CommandBarView` | 该话题的回执动词由「已下达 / 未下达」改为「已办理 / 未办理」——买是即时过户、申请是即时递单，说「下达」会让人以为还要等一道批 |

拒绝文案明写「本次**未成交、未扣款、未改台账**」，并指出两条正路（等挂牌 / 改说「申请 …」走免费的协调池）。

### 负面控制

且报错正是玩家看到的症状：

```
R48 ①「购买SIN 12:00时刻槽」没被认成时刻槽事务（topic= ok=True apt= clock= buy=False）
      —— 这会派给运营部，回一封与买槽无关的网络总账。
R48 ② 货架没货时应「未成交」并且不发信：ok=True …
R48 ③ 有挂牌却没成交：ran=False … 货架余 1
```
