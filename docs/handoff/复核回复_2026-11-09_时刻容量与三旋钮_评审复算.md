## 0. 结论

反馈判断方向成立，三项采纳；但反馈与本报告原稿共同建立在"81 座机场"这一错误前提上。引擎实际为 **104 座录入 / 103 座协调**，所有验收标准需按 103 场重写。

| 项 | 判断 |
|---|---|
| ÷27 作为"数值不变"迁移 | 否决（采纳反馈的 C0） |
| 全局误差掩盖局部误差 | 采纳，且原报告 +1.8%／≤2 架次有误 |

## 1. ÷27 逐场对照

引擎真实跑道表口径：现状合计 **248**，÷27 合计 **248**（精确相等），逐场变化 **46** 场，最大 ±3。

反馈口径（研究表跑道列）为 249 / 248 / 45 场。

【关键】总量精确相等却逐场漂移，等于"拆东墙补西墙"，单看世界总量无法发现问题。

## 2. D16 双向对称取整偏差

- 全局：理论 3,401 → 实际 3,480 架次/时，**+2.32%**（原报告误写 +1.8%）
- 单场最大：**±4 架次/时**（原报告误写"≤2"）
- 超发最大：TSN +33.3%、ZUH +28.0%、SCL +20.0%、HAK +18.5%、MNL +14.3%
- 少发最大：SYX -20.0%、LIM -15.8%、NKG -15.8%、BNE -11.1%、WUH -11.1%

反馈给出的 LHR +9.1%、BKK +11.1%、TSN +33.3%、SYX −20.0% 均复算一致。

## 3. 凌晨归属

| 度量 | 数值 |
|---|---|
| 四段容量（早/中/晚/夜） | 10756 / 6080 / 6080 / 4636 |
| 早班池占全局 | 39.0% |
| 其中 00:00–05:45 | 21.4% |

成因：`QuarterCapacityRaw` 改为"跑道数平铺"后，00:00–05:45 不再恒为 0；但 `BandOfDep` 仍把 `h < 10` 判给早班、`BandHourStart(0) = 6` 未改、`MatrixGrid` 仍按 06:00–09:45 裁列。

结论：撤回"改标签"建议；不改边界则七分之一容量挂在错误标签下。

## 4. 峰刻锁死

判据：每刻每方向容量 C、占用率 r，轮转底座 ⌊C·r⌋；当 C ≤ 1/(1−r) 时峰刻余量恒为 0。r = 87% → C ≤ 7 必锁。

D16@87% 仅 15 场 C ≥ 8：ATL、BOS、CLT、DEN、DFW、DTW、IAH、LAS、LAX、MCO、MIA、MSP、ORD、PHX、IST（除 IST 外全为美国场）。

D16@75% 仍 25 场为 0，根因是申报值偏低（WUH 36、TSN 24、URC 44、HAK 27），非分配算法。A1 必须绑定 P0 数据校核。
