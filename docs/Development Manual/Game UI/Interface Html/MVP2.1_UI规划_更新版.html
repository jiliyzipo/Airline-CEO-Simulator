关键设计规则

规则说明
无左侧菜单导航不再使用左侧竖列菜单，改为底部横向 Tab 栏。每个 Tab 切换整屏内容。
顶部三要素顶部固定显示「公司LOGO + 公司名称 + CEO名字」三块白色标签，增强角色代入感。

两栏详情收件箱、机队等二级页面采用「左侧列表 + 右侧详情」的双栏布局，信息层级清晰。
深色科技风整体采用深蓝/深灰背景 + 亮蓝/亮白文字的配色方案，模拟航空驾驶舱/指挥中心风格。

一、各界面详细规划（主界面 + 二级/弹窗）

🏠 主页（Home）
  • 世界地图背景 + 航线动画
  • 覆盖 4 块蓝色数据面板:
    ① 现金跑道（月数+趋势）
    ② 下一件待办事项
    ③ 航线统计 ▼
    ④ 检修计划 ▼
  • 4 个 KPI 卡片横排: 董事会满意度 / 机队规模+可用率 / 本季净利润 / 市场趋势
  • 员工满意度 + 媒体报道 两大主题区
  • 底部"主页"Tab 高亮
📬 收件箱（Inbox）
  • 左侧列表：按日期分组的邮件，含发件人 + 主题 + 未读标记
  • 右侧详情：选中邮件的完整内容，包含：
    • 发件人 / 抄送
    • 正文（如航线申请分析）
    • 预估收益 vs 成本 柱状图
    • 底部决策按钮（批准开航 / 发起会议 / 暂缓）
  • 部门邮件自动抄送相关人员
🛩 机队（Fleet）
  • 顶部统计栏：总飞机数 / 平均机龄 / 可用率
  • 左侧机型列表：A330 / A321 / A320 / B738 / B737，每行带数量 + 展开箭头 ▶
  • 右侧明细表：注册号 / 座位数 / 首飞日 / 机龄
  • 点击注册号进入飞机详情
  • 右上角「+ 购买飞机」按钮
🛩 飞机运行界面（Aircraft Detail）
  • 顶部：机型 / 编号 / 飞行总里程 / 飞行时长 筛选标签
  • 飞机实物图（带航司涂装）
  • 4 块蓝色数据面板：
    • 飞行基本信息（时长/里程/WiFi/餐食/首飞日/基地）
    • 飞行记录（近30天执飞/计划班次）
    • 检修信息（距A/B/C/D检天数 + 历史记录）
    • 财务信息（购买金额/检修成本/月持有成本）
  • 底部操作：分配航线 / 转售退役 / 安排大修 / 申请替换
🗺 航线（Routes）
  • 世界地图视图 + 公司航线高亮
  • 航线列表（航线、执飞机型、周班次、客座率、日利润）
  • 点击航线查看 RPM 评分 + 竞争分析
  • 右上角「+ 开通新航线」按钮
  • 覆盖城市数 + 总航线数统计
💬 航空事务官（AO 引导页）
  • 大型蓝色对话气泡覆盖地图
  • 三段式介绍：
    ① 欢迎语 + 角色设定（25年飞行经验）
    ② 我能为您做三件事（主动预警 / 随时答疑 / 引导上手）
    ③ 界面功能速览表（一行一功能）
  • 右下角常驻悬浮 AO 头像（绿/黄/红呼吸灯）
  • AO 不说话时不自动弹窗
💰 财务部（Finance）
  • 现金跑道大号油量表（环形仪表盘）
  • 关键数字：本季净利润 / 总营收 / 总成本
  • 燃油对冲面板（当前价 / 已锁吨数 / 到期日 / 盈亏状态）
  • 宏观经济指示灯（扩张/收缩/危机）
  • 「🚨 紧急融资」按钮（红底白字）
📈 市场销售部（Marketing）

⚙️ 运营部（Operations）

二、CEO 决策会议（开航线 / 买飞机）

触发方式： 由收件箱邮件中的「发起会议」按钮触发，或从运营部/机队页面的快捷入口触发。会议以全屏覆盖弹窗形式呈现。

会议面板布局

  • 顶部议题栏：蓝底白字，如「议题：关于引进 1 架 A320neo 的采购提案」
  • 中部 5 部门卡片（横排），每张卡含：
    • 🔴 财务部：现金储备、负债率、融资成本
    • 🟢 运营部：运力提升、日利用率改善
    • 🟡 市场部：预估客座率、RPM 评分
    • 🔴 人力资源部：飞行员/机务缺口、培训成本
    • 🟢 安全质量部：适航合规评估
  • 底部决策按钮：✅ 批准（推进）/ ⏸ 暂缓（补充条件）/ ❌ 拒绝（搁置）

快捷决策 vs 完整会议

  • 首航（强制简化）：AO 代为主持，玩家直接点击「确认首航计划」
  • 后续重大投资：必须走完整跨部门会商流程

三、航空事务官（AO）—— 单人 AI 副驾驶

3.1 角色设定

  • 称呼：小航，25 年航空业经验虚拟形象。
  • 常驻位置：主界面右下角悬浮圆形头像，带呼吸光效： 绿 正常 黄 有待阅建议 红 紧急预警

3.2 三大交互模式

模式触发行为
新手引导（强制）开局自动弹出全屏 AO 介绍页介绍角色 + 能力 + 界面布局，不可跳过但可关闭
主动预警系统检测异常（现金<3月、AOG等）头像变色 + 点击弹出预警建议
被动问答玩家点击头像打开对话框预设按钮问答（开航线/买飞机/看报表/风险提醒/运营效率）

3.3 AO 对话窗

  • 右下角弹出 360×480 对话框
  • 历史对话记录 + 6 个预设快捷按钮
  • AO 回复：结论前置 + 1 个核心建议 + 1 个快捷跳转按钮

六、设计原则与约束

  • 导航在底部，不在左侧：所有主界面切换通过底部 Tab 栏完成。
  • 世界地图为视觉锚点，不是可操作地图（MVP阶段）。
  • AI 建议不自动执行，AO 预警需玩家确认才跳转。
  • 文案通俗化，专业术语配 Tooltip（Phase 14 已实现）。
  • 深色主题 + 蓝白色系 = 航空驾驶舱风格。
  • 弹窗全屏覆盖，底部有决策按钮而非灰色关闭键。
