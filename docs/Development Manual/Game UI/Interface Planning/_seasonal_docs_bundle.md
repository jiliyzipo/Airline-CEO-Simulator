定位
航空公司竞争情报中心。将竞争从“票价”升级为涵盖 7 大维度 的全面战争，让 CEO 清晰感知我司与竞对在各维度的优劣势，为战略决策提供数据支撑。
📋 功能列表
模块一：顶部 · 竞争态势总览
竞争雷达图（核心视觉）：七边形雷达图，展示我司与主要竞对（最多4家）在 航线网络 / 定价收益 / 产品服务 / 运营成本 / 辅助收入 / 外部环境 / 战略资本 7 个维度的综合评分对比（0-100分）。我司用亮蓝色高亮，竞对用半透明灰/其他颜色。
综合竞争力排名：基于雷达图各维度加权计算的总分排名，显示“我司 vs 行业平均 vs 最强竞对”的相对位置。
竞争态势总评：AO 生成的一句话态势判断：“您在当前市场处于挑战者地位，领先优势在航线网络，主要威胁来自云翼的定价能力。”
时间轴滑块：拖动查看过去 12 个月的竞争态势变化趋势（雷达图动画演变）。
模块二：主要竞对卡片（横向 4 张）
竞对 Logo/名称/类型：如“云翼航空 · 全服务”，显示当前状态（稳态/进攻/防御/垂死）。
综合得分：雷达图加权总分。
强项标签：从雷达图中自动提取最高分维度（如“定价收益”“航线网络”）。
弱项标签：从雷达图中自动提取最低分维度（如“辅助收入”）。
最近动态：一句话摘要（如“上周在深圳-北京航线降价 8%”）。
点击卡片：下钻至 L3 竞对详情页。
模块三：逐维对标分析（7 个 Tab 切换）
这是页面的核心分析区，采用 Tab 切换展示 7 个竞争维度的详细数据对比：
✈️ 航线网络 💰 定价收益 🛋️ 产品服务 ⚙️ 运营成本 💳 辅助收入 🚄 外部环境 🧠 战略资本

实时动态列表：显示竞对的最新动作（如“云翼航空申请开通北京-伦敦航权”、“青鸾航空在成都-上海航线降价5%”），按时间倒序排列。
事件类型标签：标注事件类型（航线扩张 / 价格战 / 联盟合作 / 资本运作 / 安全事件）。

竞争策略建议：AO 基于雷达图分析，给出 3 条具体建议（如“云翼在深圳-北京持续降价，建议差异化提升服务而非跟进价格战”）。
机会预警：识别竞对弱项，提示我司可进攻的方向（如“北辰货运辅助收入薄弱，可加大腹舱营销抢占份额”）。
一键执行：每条建议底部含跳转按钮（如“去市场部调整定价”、“去战略部申请航权”）。
