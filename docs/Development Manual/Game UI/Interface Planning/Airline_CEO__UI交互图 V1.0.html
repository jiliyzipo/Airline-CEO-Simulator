A. 页面层级定义（一级～五级） 先看这个
规则：同级 Tab 互切不算「进入下级」；只有「列表→详情→子页→弹窗→二次确认」才算加深一层。
L0
壳/元流程
未进游戏 / 常驻框架：主菜单、玩家资料、公司注册、董事会抽卡、年度目标确认；进游戏后的顶部栏+地图底+底部Tab壳、AO头像、消息铃铛、速度/暂停。
主菜单公司注册董事会组建主界面框架
L1
一级页面
底部 Tab 整屏切换（同一层级，互相平级）：主页、收件箱、机队、航线、运营、市场、财务、战略、机务、人力、安全、董事会。
🏠主页📬收件箱🛩机队🗺航线七部门+董事会
L2
二级页面
从 L1 点进的详情/分栏页：飞机详情、消息中心、宏观经济、竞争态势、随机事件日志、设置/存档、飞行学院、历史回放、AO对话窗（半屏）。
飞机详情消息中心宏观面板竞争态势
L3
三级工作台
从 L1/L2 再钻入的专业子界面：座位配置、对冲工作台、碳配额、FFP、产品工坊、RPM评估台、航班环构建器、工会谈判桌、预算编制界面。
座位配置对冲台RPM评估航班环
L4
四级弹窗
覆盖层决策（盖住当前页，不换底Tab）：CEO决策会议、危机IRROPS、紧急融资/破产、部门负责人任命、财年续聘/解雇、合同签署弹窗。
决策会议危机弹窗紧急融资续聘/解雇
L5
五级确认
弹窗内的二次确认 / 条件补全：会议「暂缓→补条件」、融资方式确认、破产保护条款勾选、任命薪酬确认、删除/退役二次确认。
二次确认框补条件表单条款勾选
