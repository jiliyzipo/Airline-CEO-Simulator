# Airline CEO Simulator · 本机开发环境检查清单

> 对照《技术任务书 v1.0》使用。完成一项就把 `[ ]` 改成 `[x]`。

---

## A. 基础软件

- [ ] 已安装 **Git**，终端可执行 `git --version`
- [ ] 已安装 **Cursor**，能打开本仓库并对话
- [ ] 已安装 **Unity Hub**
- [ ] 已通过 Unity Hub 安装 **Unity Editor（LTS）**（建议 2022.3 或 6000.x LTS）
- [ ] Unity 安装时已勾选 **Windows Build Support (IL2CPP 或 Mono 均可，先有其一）**
- [ ] 已安装 Unity 提示的 **Visual Studio** 或 **VS Code + C# / Unity 扩展**
- [ ] 本机有足够磁盘空间（建议预留 **≥ 20GB** 给 Unity 与工程缓存）

---

## B. Unity 工程就绪

- [ ] 已用 Unity 新建空项目（2D 或 3D 均可）
- [ ] 工程路径已确定（建议放在仓库内，如 `UnityProject/`，或单独目录并说明）
- [ ] 打开空场景后点击 **Play**，无红色报错
- [ ] 首次创建 UI 时，已按提示导入 **TextMeshPro（TMP）** 基础资源
- [ ] 已确认工程使用 **UGUI**（Canvas / Button / Text 等，与任务书一致）
- [ ] （建议）已加入 Unity 版 **.gitignore**（排除 `Library/`、`Temp/`、`Logs/` 等）

## C. 账号与 API（DeepSeek）

- [ ] 已注册 **DeepSeek** 开放平台账号
- [ ] 已创建并复制 **API Key**
- [ ] 已充值少量额度（或确认免费额度可用）
- [ ] 本机网络可访问 DeepSeek API（浏览器或简单请求测试通过）
- [ ] 已约定 Key 的存放方式（环境变量 / 本地未入库配置文件）
